# Vicco Aguilar | Portfolio

Static site for GitHub Pages. No build step.

- `index.html` is the home page (one long page).
- `case-studies/` has one page per case study, with images in `case-studies/img/`.
- `images/` holds the home page artwork and logos.

## Publish
1. Create a public repo named `YOURUSERNAME.github.io` (or any name for a project site).
2. Upload everything in this folder to the repo root (keep `.nojekyll`).
3. Settings > Pages > Deploy from a branch > `main` / root.
4. Wait a minute, then open `https://YOURUSERNAME.github.io/`.

All links are relative, so it works at the root or under `/repo-name/`.
